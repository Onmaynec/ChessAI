# Chess AI Vision v0.7.7 — Queen Promotion Reclick

Исправление для установленной **Chess AI v0.7.6 Vision Live Analysis**. Не является полной игрой.

## Что исправлено

Раньше на ходе `b2b1q` или `a7a8q` Vision Bot делал два клика (пешка, клетка назначения), а затем только ждал, пока сумеет распознать ферзя или меню. При всплывающем меню это приводило к остановке.

Теперь при **выбранном нейросетью превращении именно в ферзя (`q`)**:

1. Vision Bot нажимает исходную и конечную клетки.
2. Проверяет, не появился ли ферзь автоматически. Если появился — повторного клика нет.
3. Если ферзь не распознан, Vision Bot **один раз** кликает по центру клетки назначения (или по распознанной кнопке ферзя в меню).
4. Проверяет появление ферзя и затем подтверждает весь ход обычным распознавателем.

Пример: `b2b1q`: клик по **b2**, клик по **b1**, дополнительный клик по **b1**, проверка ферзя. Работает при обеих ориентациях доски и превращении со взятием.

Если превращение было **в ладью, слона или коня**, остаётся прежний безопасный алгоритм распознавания меню. Если изображения недостаточно, программа останавливает клики вместо бесконечных повторов.

## Установка на Windows

1. Закрой Vision Bot. Отдельный процесс self-play можно не останавливать.
2. Распакуй **весь ZIP** в отдельную папку.
3. Запусти `INSTALL_QUEEN_RECLICK.bat`.
4. Введи полный путь к установленной папке Chess AI, где лежит `START_CHESS_VISION_BOT.bat`.
5. Подтверди `YES`, затем снова запусти `START_CHESS_VISION_BOT.bat`.

Установщик проверяет исходную версию и SHA-256 файлов. Он сохраняет резервную копию заменяемого файла в `config/vision_patch_backups/v077_queen_*` и не работает с `runs`, `models`, checkpoint или виртуальными окружениями.

## Ограничения и тестирование

- Патч предназначен для режима Chess.com **против компьютерного бота**, не для рейтинговых игр против людей.
- Успех требует, чтобы меню Chess.com действительно позволяло выбрать ферзя вторым кликом по клетке назначения. В других темах сайта или при перекрытии доски меню может отличаться.
- Дополнительный клик строго ограничен одним. На неопределённой позиции программа не продолжает нажимать.
- Тесты проверяют белые и чёрные превращения, превращение со взятием, уже включённое auto-queen, выбор ферзя из меню и отсутствие лишнего клика на обычном ходе.
- Живой браузер на компьютере пользователя в этой среде недоступен: проверить работу нужно на реальной тренировочной партии против бота.
