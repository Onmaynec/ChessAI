# Локальная конфигурация

- python_path.txt — необязательный путь к существующему python.exe.
- vision_bot.json — пользовательская калибровка, создаваемая GUI. Не публикуется.
- vision_bot.example.json — только пример структуры, не реальные координаты владельца.

Не заменяйте рабочие локальные настройки примерами.
