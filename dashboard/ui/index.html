БЕЗОПАСНОЕ ОБНОВЛЕНИЕ

Сохранность обучения

При обновлении переносятся каталоги runs, models и output. Проверяются хеши файлов; старая установка не удаляется. Веса модели и состояние оптимизатора находятся внутри runs/<ID>/checkpoints/latest.pt. После переноса можно продолжить исходную итерационную последовательность. Полную проверку checkpoint выполняет scripts/VERIFY_PROGRESS_WINDOWS.bat.

О СИСТЕМЕ / МЕТОДИКА

Как читать результаты.

Что действительно измеряет система и как выбирать длительность обучения.

01 / ОБУЧЕНИЕ

Реальное self-play

Нейросеть играет сама против себя. Правила, рокировки, шахи, маты и ничьи определяет C++ ядро. Во время партии сеть выбирает действие только из допустимых ходов.

02 / ОБНОВЛЕНИЯ ВЕСОВ

On-policy PPO

После завершения партий известный исход превращается в награду −1, 0 или +1 для каждого игрока. PPO обновляет стратегию, Value MSE обучает прогнозировать исход. Незавершённые игры исключаются из обновления.

03 / ИНТЕРПРЕТАЦИЯ

Loss ≠ сила игры

Policy loss может быть отрицательным и не обязан монотонно снижаться. Value MSE показывает ошибку прогнозирования исходов в текущих партиях. Реальный рост силы проверяется независимыми матчами с фиксированным соперником.

04 / УПРАВЛЕНИЕ

Эксперименты и чекпойнты

Нажмите «Новое обучение», выберите пресет и запустите. Статистика автоматически обновляется каждые 2,5 секунды. «Остановить» завершит текущую итерацию и сохранит checkpoint; остановленный запуск можно продолжить.

Сведения о текущем релизе

Видеокарта используется только если установлен PyTorch с поддержкой CUDA. RTX 3050 ускорит часть операций, но скорость зависит от числа партий, размера модели и работы шахматного ядра. Это ранний исследовательский прототип: не обещает Elo, не играет на чужих аккаунтах и не подменяет движки шахматных сайтов.

Исходный supervised checkpoint v0.2 включён как стартовая модель. Без накопления достаточного числа завершённых партий сигнал подкрепления будет слабым. Для качественного сравнения используйте длительные тренировки и серии проверочных матчей.
