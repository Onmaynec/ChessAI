# Vision Studio — UI 0.8.3

Новая оболочка на CustomTkinter: графитовые панели, фиолетовый акцент, русская и английская навигация, адаптивная компоновка. При узком окне карточки располагаются вертикально. Оригинальные сообщения движка пока остаются на русском.

Запуск: в выбранном Python установите `python -m pip install "customtkinter>=5.2,<6"` (без переустановки Torch), затем `START_CHESS_VISION_BOT.bat`. Для работы нужны прежние зависимости, собранный C++-движок и локальные checkpoint.

Сессия: выберите агент, задайте область, сторону и глубину, подтвердите компьютерного соперника. Новый запуск и подключение к текущей позиции — разные кнопки. Параллельное локальное обучение по умолчанию отключено; включается явно. Смена агента остаётся доступна между ходами.

Видение показывает последнюю FEN-позицию из событий, не изображение экрана. Оценка cp относится к стороне хода; policy не является вероятностью победы. При отсутствии данных отображается прочерк. Фильтры журнала не удаляют журнал на диске.

Оверлей: кнопка в заголовке переключает то же окно в 344×278. Перемещение за заголовок, остановка по Esc, раскрытие панели. Прозрачность 55–100% задаётся в настройках и сохраняется в config/vision_ui.json. Оверлей всегда видим, не click-through. При раскрытии во время игры сохраняется одна сессия, если панель помещается рядом. Иначе раскрытие блокируется до остановки. При перекрытии доски также запрашивается остановка. Это интерфейс для разрешённых испытаний против компьютерного соперника, не инструмент скрытой помощи в человеческих партиях.

Кодировка, PPO, веса и recovery не меняются. Полная проверка графики, DPI, захвата и Windows focus требует локальной проверки.

## Reference Match Pass

При ширине окна от 1050 пикселей: слева навигация, сверху статус, в центре компактная настройка, справа доска и краткий анализ, снизу закреплённый журнал. В узком окне настройки остаются на странице сессии, запуск и подключение закреплены снизу, остальные страницы доступны в навигации. Детальный текст анализа доступен на странице «Анализ». Полосы кандидатов показывают policy, не вероятность победы. Системные индикаторы проверяют наличие файлов и калибровки, не показывают вымышленные CPU/GPU метрики.
