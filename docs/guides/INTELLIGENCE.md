# Chess AI v0.7.1 — Intelligence & Tactical Guard

**Дополнение для установленной Chess AI v0.7.0 с Vision Computer Bot.**

## Почему нейросеть проигрывала

Ранее `botlab/session.py` использовал `rank()` и брал самый вероятный легальный ход из модели, не оценивая ответы соперника. 1018 итераций PPO само по себе не даёт сильную шахматную стратегию: обучение преимущественно на собственных ошибках может стагнировать.

## Что в патче

- `neural/intelligence.py` — проверка **каждого** легального корневого хода собственной C++ alpha-beta оценкой на 5 полуходов (один ход игрока + 4 полухода поиска после него). Одно UCI-подключение используется для всех вариантов; если поиск слишком долгий, предусмотрена попытка на меньшей глубине. На реальной Windows скорость и устойчивость не измерялись.
- Дебютный репертуар из семей итальянской партии, сицилианской защиты, французской, Каро-Канн, ферзевого гамбита, английского начала и других коротких вариантов. Только легальные ходы. Дебютная подсказка **не побеждает явный тактический проигрыш**.
- Бонусы за развитие лёгких фигур, захват центра и рокировку; штрафы за преждевременные ходы ладьёй и ферзём.
- Штраф за возвращение фигур на предыдущую клетку и повторение позиций, если тактически близкие альтернативы имеются. Повторение, спасающее от поражения, не запрещается.
- В выборе между **тактически близкими** ходами участвует вероятность обученной ChessNet. Полностью нейросетевая игра не заявляется — это гибридная система.
- В журнале Vision Bot теперь показываются глубина поиска, оценка выбранного хода (сотые пешки) и предупреждение при недоступности тактического поиска.
- `neural/skill_boost.py` — **необязательное** дообучение отдельной копии текущей сети на синтетических позициях, размеченных встроенным C++-движком. Цель — чтобы веса самой сети могли перенять хотя бы часть более рациональных решений. C++ учитель слабый, это не Stockfish и не гроссмейстерские партии. Улучшение потерь на контрольной выборке не доказывает прирост шахматной силы.

## Установка

1. Закрыть окно Vision Bot; работающий локальный self-play останавливать не нужно.
2. Распаковать ZIP в отдельную папку, запустить `INSTALL_CHESS_INTELLIGENCE.bat`.
3. Ввести корень установленной Chess AI v0.7.0, содержащий `neural`, `botlab`, `visionbot`, `runs`:

   `C:\Users\Мамлеев Роман\Downloads\ChessAI_v0.7.0_Training_Performance_Intelligence\ChessAI-v0.7.0`

4. Подтвердить `YES`. Установщик сохранит `.before_intelligence_071.bak` для трёх заменяемых файлов. Он **не трогает** `runs`, `checkpoints`, `models`, `.venv-cuda`, `requirements.txt`.
5. Начать **новую** шахматную партию с начальной позиции против компьютерного бота (не людей) и запустить `START_CHESS_VISION_BOT.bat`.
6. Для чистого теста можно убрать галочку «Параллельно продолжать self-play», если самообучение уже выполняется отдельно. Это не останавливает уже запущенный тренер.

## Тест на изменение реальной силы

Сравнить минимум 10–20 партий `latest.pt` **после установки патча** с тем же ботом Chess.com и прежними 5 поражениями до патча. Записывать победы / ничьи / поражения, длительность партии и повторения. Нейросеть не обязана выигрывать каждый раз. Факт исправления нелепых ходов не означает доказанного роста собственных весов.

## Необязательное настоящее дообучение весов

Запустить в корне проекта `TRAIN_SKILLBOOST.bat`. Скрипт использует `latest.pt` из указанного пользовательского run только для **чтения**, создаёт небольшой локальный набор примеров через `chessai.exe teacherdata`, обучает отдельный кандидат и сохраняет **`runs/run_20261123_072154_6a110b/checkpoints/skillboost.pt`** только если validation-loss уменьшился по сравнению с исходной копией. Это может занять время. В Python CLI:

```powershell
.\.venv-cuda\Scripts\python.exe -m neural.skill_boost --run runs\run_20261123_072154_6a110b --engine build\Release\chessai.exe --samples 1200 --depth 4 --epochs 6 --device auto
```

Этот checkpoint **нельзя использовать вместо `latest.pt` для `selfplay --resume`**: у него отдельный процесс обучения и нет оригинального PPO-оптимизатора. Если кандидат создан, можно отдельно выбрать `skillboost.pt` в Vision Bot и сравнить его результат с `latest.pt`. `best.pt` не перезаписывается. Существующий self-play по-прежнему продолжает обучение исходного `latest.pt`.

Тренировочный эксперимент и веса никогда не изменяются установщиком. Против компьютерных ботов на Chess.com тестируйте с учётом условий сервиса. Онлайн-игры не используются как обучающая выборка; локальный self-play независим от них.
