# Intelligence Benchmark v0.9.1

Локальная оценка без обучения. Перед запуском остановите тренер и Vision Bot, чтобы веса и GPU не менялись. Запуск из корня: START_INTELLIGENCE_BENCHMARK.bat. Python и C++-движок должны быть установлены. Новых зависимостей нет.

## Режимы

Quick: 2 уникальных стартовых позиции, Standard: 6, Full: 8. Для каждой пары доступных агентов две партии на каждый старт с обменом цветов. Во всех профилях 18 синтетических позиций проверяются в двух режимах: чистый policy argmax и штатный гибрид с фиксированной глубиной (по умолчанию 2, без глубокого прохода). Quick/Standard проводят турнир policy; Full добавляет гибридный турнир. Одинаковые настройки balanced/standard для всех checkpoint нужны для изоляции качества весов; персональные стилевые бонусы и Phantom-книга не измеряются отдельно. Full для восьми моделей — 896 партий, может быть очень дорогим. Количество партий и глубину можно изменить через CLI.

```
python -m benchmark.run --run runs/run_20261123_072154_6a110b --engine build/Release/chessai.exe --output benchmark_reports/my_first --profile quick
python -m benchmark.run --run runs/run_20261123_072154_6a110b --engine build/Release/chessai.exe --output benchmark_reports/validation --validate-suite
python -m benchmark.run --help
```

Пример сравнения двух весов: добавьте --agents latest.pt best.pt --pairs 6. Отчёт не перезаписывается; выберите новый каталог. Пропущенные checkpoint фиксируются, несовместимый checkpoint останавливает эксперимент.

## Контрольные задачи

18 авторских позиций (9 исходных + цветовое отражение), категории: мат в 1/2, вилка, связка, жертва, защита, эндшпиль. Маты проверяются исчерпывающим AND/OR деревом легальных ходов C++ в ограниченном числе полуходов. В жертве проверяется заданное решение с доказуемым матом. Прочие задачи — согласие с заранее выбранным мотивом/ходом, не доказательство единственного лучшего хода. Размеры категорий малы. Сценарии синтетические, не полноценная оценка всех шахматных навыков.

Файл benchmark/suite_v1.json не используется обучающими entry points. Записывается SHA-256 набора, движка и checkpoint; исходные веса не модифицируются. По умолчанию проверяются текущие и архивные experience.jsonl выбранного run: точные совпадения первых четырёх полей FEN исключаются из оценки. --skip-audit явно отмечает отсутствие проверки. Это не гарантирует отсутствие совпадений с прежними supervised/SkillBoost наборами, другими runs, симметричными позициями или будущим self-play. Для долгосрочного независимого holdout нужен новый закрытый набор, не используемый при настройке. Не добавлять отчёты/задачи в обучение.

## Результаты

report.json: метаданные, SHA-256, настройки, фактические конфигурации и размер моделей, ответы по позициям и категориям, отдельно белые/чёрные, top-3 для policy, median/p95 wall-clock, CUDA peak allocated/reserved (не вся VRAM процесса), пропущенные агенты, турнир. games.jsonl: протоколы. report.md: читаемый паспорт. При прерывании JSON и завершённые записи партий остаются; перезапуск в новый каталог, продолжение прерванного турнира не реализовано.

Рейтинг — регуляризованный Bradley–Terry с дробными результатами ничьих и средним 1500 по текущему составу. Только завершённые парные игры, гибридные пары с fallback исключаются. Bootstrap по идентификатору стартовой позиции, 300 попыток; 95% интервал не публикуется при менее пяти доступных блоках или недостатке связных повторных выборок. Неполные партии отдельно, не ничьи; при отсутствии связного графа рейтинг не рассчитывается. Это внутренний рейтинг, не FIDE/Chess.com Elo, интервалы условны на данной выборке и завершённых парах. Сравнивать версии при одинаковой конфигурации, составе, seed и бюджете. Отдельный гибридный режим не измеряет абсолютную силу движка, и fallback не выдаётся за полноценный поиск.

Не производится автоматическая promotion best.pt. Данные в runs, models, optimizer и конфигурации не записываются. Показатели производительности зависят от устройства и фоновой нагрузки. Не применять результаты как помощь в партиях с людьми.

## Hotfix v0.9.2 — Audit progress

После выбора профиля Windows launcher предлагает быстрый диагностический запуск без аудита или полный скан архивов. Первый вариант явно помечается как непроверенный на пересечение с обучением и не заменяет независимый holdout. Полный аудит выводит текущий файл, приблизительную долю прочитанных байтов, число FEN и совпадений; повреждённые записи отражаются как частичная проверка. На больших архивах полный аудит всё ещё может занимать значительное время. При Ctrl+C во время аудита сохраняется report.json со статусом interrupted. Записи тренировки не меняются.
