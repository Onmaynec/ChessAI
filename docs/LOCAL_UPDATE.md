# Локальное обновление и данные

Перед обновлением остановите Training Studio, обучение и игровые интерфейсы; дождитесь записи checkpoint. Сделайте независимую копию runs на другом диске.

В существующей установке сохраняйте прежнее расположение runs/, models/, config/, .venv/, .venv-cuda/, output/ и build/. Не копируйте virtualenv в другое место: абсолютные пути могут перестать работать. В config/python_path.txt можно указать существующий интерпретатор.

Переход 0.8.1: старые корневые TRAIN_*.bat переехали в scripts/, старые документы — в docs/guides и docs/archive. patch_backups, config/vision_patch_backups и migration_reports исключены из Git; при локальной уборке перемещайте их только в резервную папку. config/vision_bot.json — локальная калибровка, не заменяйте её примером.

Для чистого Git checkout используйте git pull --ff-only только после проверки локальных изменений. Если калибровка была отслеживаемым файлом старого коммита, скопируйте её отдельно и восстановите после pull. Не используйте git clean -fdx, reset --hard или принудительную замену ветки.

После обновления запустите scripts/VERIFY_PROGRESS_WINDOWS.bat и проверьте номер итерации и optimizer. Затем откройте START_CHESS_AI.bat. Не запускайте обучение, если проверка не прошла.
