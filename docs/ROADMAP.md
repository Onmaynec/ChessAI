# Дорожная карта

## Текущая база: 0.8.1
Консолидация структуры после Phantom-X23, чистое дерево Git и документация. Алгоритмы и формат весов не изменены.

## Следующие направления (план)
1. Воспроизводимые Windows/CUDA smoke tests, единая конфигурация запуска и проверка всех entry points.
2. Независимый тактический набор, фиксированные матчевые протоколы и объективная оценка специализаций.
3. Усиление C++ поиска и оценки, проверка эффектов на holdout; исследование search-guided learning.
4. Улучшение эффективности self-play и надёжности recovery по измерениям на целевом ПК.
5. Стабилизация интегрированной версии 1.0 без нарушения совместимости сохранений.
