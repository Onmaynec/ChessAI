# Chess AI v0.6.0: фактические проверки

**Платформа разработки:** Linux, Python 3.13.5, PyTorch 2.10.0+cpu. Windows, NVIDIA-драйвер и CUDA на компьютере пользователя в этой среде недоступны. Ниже не заявляется GPU-ускорение и не смешиваются бенчмарк синтетической сети с силой шахматного ИИ.

## Автоматические проверки

47 Python unit/integration тестов прошли; C++ CTest прошёл в чистой Release-пересборке; синтаксис JavaScript и все используемые ID HTML проверены. Сборка на Windows и CUDA на компьютере пользователя остаются непроверенными.

## Изменения

- Новый контроль PPO: approximate KL, ранняя остановка, clip fraction, grad norm, защита от нечисловых весовых обновлений.
- Self-play league с несколькими замороженными snapshot, собственные on-policy выборки, логирование соперника.
- Малый штраф за немедленное обратное перемещение при генерации тренировочной партии без запрета шахматных ходов; тот же prior учитывается в PPO.
- Аналитика причины завершения партии (в т.ч. троекратные повторы) и числа повторно посещённых FEN.
- Парные контрольные матчи с выбором selection/holdout seed; требование пройти оба набора перед promotion в best.pt.
- CPU/CUDA микро-бенчмарк и цветовой audit без модификации checkpoint.

## Проверка совместимости с реально предоставленным сохранением

Проверен файл `run_20261123_072154_6a110b/checkpoints/latest.pt` из предоставленного ранее архива (170 итераций). Сеть загрузилась как `{'channels':32,'blocks':2}`, состояние оптимизатора присутствует. Копия с `--resume --iterations 1 --games-per-iteration 2 --max-plies 36 --opening-plies 8` сохранилась как 171-я итерация. 23 внутренних состояния оптимизатора остались доступными после сохранения, хотя выбранный короткий тест не завершил партии и не делал PPO-обновлений — **рост силы не проверялся**.

## Известные ограничения

- Антиобратный штраф эвристический: повторение полной шахматной позиции требует учёта иных факторов; законная ничья по повторению остаётся разрешена.
- Лига сама по себе не даёт гарантий усиления без достаточно сильных соперников и сигнала побед/поражений.
- Отложенный seed не гарантирует отсутствие повторяющихся дебютных позиций между наборами.
- Цветовая инволюция для анализа сети — *синтетический FEN*, не поддержка альтернативных шахматных правил; большой разрыв Value указывает на возможный перекос и требует дальнейшего расследования.
- `results.score` — результат против конкретного оппонента при заданных условиях, а не Elo. Все устаревшие метрики сохраняют прежнюю интерпретацию; в v0.6 не додумываются данные о причинах ничьих для v0.5.
- Версия не обеспечивает игру на сторонних шахматных сайтах и не нарушает правила площадок.
