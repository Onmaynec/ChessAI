# Архив

Исторические инструкции миграции, отчёты тестирования, метрики и заметки отдельных патчей. Они не являются инструкциями текущего релиза. Манифест 0.7.0 хранится для истории и не проверяет современное дерево. Актуальные команды — в [индексе](../README.md). Старые резервные копии исходников доступны в предыдущем коммите Git; локальные копии не удаляйте без резервирования.
