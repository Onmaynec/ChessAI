# Chess AI v0.7.0 — test report

Тестовая среда: Linux container (CPU PyTorch 2.10), CMake/CTest, Python unittest. Физическая Windows + RTX 3050 не проверялась из этого контейнера.

- **55/55 Python unit/integration tests passed** (наследуемые и новые).
- **1/1 C++ CTest passed**, clean CMake release build.
- JavaScript `node --check` passed, backend Python `py_compile` passed.
- Lossless storage: у gzip-архива исходные байты восстанавливаются точно; SHA-256 сверяется до удаления оригинального `.jsonl`. Идемпотентность после сбоев, отказ при malformed JSONL и запись за границей checkpoint.
- API: просмотр партий из архива, выдача списка и информация о размере экспериментальной папки.
- Recovery: потоковое выделение незакоммиченных записей, полный восстановимый compressed backup вместо гигабайтной несжатой копии.
- CPU BridgePool: два независимых C++ процесса в одном `rollout`, тест легальности и длины истории.
- **Реальные данные пользователя**, только на копии архива `run_20261123_072154_6a110b.zip` из беседы: 170 итераций, 703 470 experience rows. До: 325,82 МиБ, после: 92,29 МиБ; сохранены 2720 игровых записей и checkpoint/AdamW. После сжатия скопированный checkpoint прошёл продолжение **170 → 171**; исходный архив не модифицирован.
- Учёт: новая итерация с лимитом 30 полуходов была незавершённой, поэтому **не** утверждается, что подтверждён прирост шахматной силы или PPO updates на этом конкретном тесте.
- `START_CHESS_AI.bat`, CUDA wheel, Windows/Python 3.14 subprocess и скорость GPU на RTX 3050 должны пройти эксплуатационную проверку пользователя после обновления.

Этот релиз не включает данные актуальной локальной 500+ итерации; их переносит мигратор на пользовательском Windows ПК.
