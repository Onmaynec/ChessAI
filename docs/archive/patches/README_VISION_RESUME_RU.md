# Chess AI v0.7.3 — Vision Match Recovery (патч)

## Что исправляет

Раньше после остановки Vision Bot требовал начать партию заново. Теперь он
**сохраняет подтверждённую историю каждого хода** и при следующем запуске
восстанавливает C++-сессию, включая FEN, очередь хода, право на рокировку,
взятие на проходе, счётчики ходов. Затем сверяет текущую доску с этой позицией.

Восстанавливаются следующие ситуации:

- Бот остановился, доска не изменилась: продолжение с сохранённого FEN.
- Пока бот был выключен, компьютер сделал **один ответный ход**: он находится
  среди законных продолжений сохранённой позиции.
- Бот успел нажать на доску, но упал до записи подтверждения: до клика
  сохраняется **write-ahead** запись UCI-хода. При восстановлении проверяется
  исходная позиция, наш сделанный ход и пара «наш ход + быстрый ответ».
- Повторный запуск после ошибки распознавания, потери фокуса браузера и
  неожиданного закрытия приложения, если журнал уже существовал.

Сверка требует **двух стабильных кадров**. При нескольких неразличимых
вариантах или несовпадении доски клики запрещены: журнал сохранится.

## Установка

1. Закрой Vision Bot (локальный self-play можно не выключать).
2. Распакуй ZIP целиком.
3. Запусти `INSTALL_VISION_RESUME_FIX.bat`.
4. Укажи корневую папку установленного Chess AI, например:

   `C:\Users\Мамлеев Роман\Downloads\ChessAI_v0.7.0_Training_Performance_Intelligence\ChessAI-v0.7.0`

5. Введи `YES`.
6. Запусти прежний `START_CHESS_VISION_BOT.bat`.

В начале новой партии оставь галочку **«Восстановить предыдущую партию
после сбоя»**. Если журнала ещё нет, программа создаст его при первом старте.
После сбоя оставь галочку включённой и снова запусти автопилот **на той же
открытой партии**. Не меняй ориентацию доски и не закрывай матч на сайте;
если браузер был перемещён или изменился размер, повторно выдели область доски.

Для намеренного начала **новой** партии сними галочку восстановления.
Перед этим доска должна быть в начальном положении. Прежняя история и
зафиксированный checkpoint будут перенесены в `vision_recovery/archive/`.

## Место хранения

`runs/run_20261123_072154_6a110b/vision_recovery/`:

- `active_white.json` / `active_black.json` — подтверждённая история, FEN,
  ожидающий подтверждения клик, контрольные суммы.
- `initial_white.png` / `initial_black.png` — эталон начальной позиции для
  распознавания контуров на выбранной теме доски.
- `frozen_white.pt` / `frozen_black.pt` — копия модели только для этой партии;
  обновления `latest.pt` во время параллельного self-play не изменят решения
  нейросети посреди матча.

**Нельзя удалять эти три файла во время партии.** Основные `latest.pt`,
`best.pt`, `skillboost.pt`, `skillboost_v2.pt`, optimizer и обучающие журналы
НЕ изменяются. Онлайн-партии не превращаются в тренировочные данные.

## Точные ограничения

- Невозможно достоверно восстановить **произвольную старую партию без
  предварительного журнала**, только по одному скриншоту: на изображении
  не видно историю рокировок, взятия на проходе и повторений. Для партии,
  начатой **до установки патча**, сначала нужна новая партия, чтобы создать
  журнал, затем все будущие сбои можно восстанавливать.
- Безопасный диапазон рассинхронизации: сохранённая позиция плюс один ход
  соперника либо заранее записанный ход ИИ плюс быстрый ответ. Если произошло
  больше неизвестных действий или изменился стиль фигур, программа остановится.
- Автоматическое восстановление не означает, что игра на сайте будет продолжена
  после того, как пользователь сам закрыл или сбросил **онлайн-партию**.
- Переключение фокуса браузера, обнаружение взятий/рокировки и существующие
  настройки SkillBoost сохранены из предыдущих патчей.
- Не устанавливай это поверх чистой v0.7.0 без последних патчей Vision:
  установщик проверяет наличие `visionbot`, а патч рассчитан на v0.7.1.2 и
  SkillBoost II.

## Проверка после установки

После нескольких ходов попробуй кнопку «Остановить» (она НЕ удаляет журнал),
затем ещё раз нажми «Запустить автопилот», сохранив галочку восстановления.
Ожидается сообщение **«Партия восстановлена: N полуходов, FEN: ...»**.

Если доска не совпадает, ты увидишь диагностику «Невозможно однозначно сверить
текущую доску с журналом». Не нужно сбрасывать партию — сначала проверь
калибровку и попробуй снова.

Примечание: это автономный Vision-прототип для компьютерных ботов. Он не является
официальной интеграцией с Chess.com; условия платформы могут ограничивать
автоматизацию даже при игре против компьютерного соперника.
