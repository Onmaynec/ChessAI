# Chess AI v0.4.0 — отчёт тестирования

Платформа: контейнер Linux x86_64, Python 3.13, PyTorch 2.10 CPU, g++ C++20, CMake. Не Windows/RTX 3050.

- **C++ шахматные правила:** CTest пройден, перфт и edge-cases входят в регрессионные тесты.
- **Python:** 23 теста, включая v0.1–v0.3 и 8 новых тестов v0.4; все успешны.
- **Миграция:** dry-run, копирование с проверкой SHA-256, конфликт, запрет копирования при активном тренировочном статусе, повторный импорт, неизменность старой папки.
- **Настоящий upgrade smoke:** оригинальный checkpoint из zip v0.3 перемещён в пустую копию v0.4, PyTorch восстановил модель и optimizer, новая итерация запущена 2→3, старая checkpoint осталась идентичной.
- **Search:** принудительный мат `g6g7` на FEN `7k/8/5KQ1/8/8/8/8/8 w - - 0 1`; все исходные ходы легальны.
- **Evaluation:** две короткие контрольные партии в эндшпиле, обе корректно завершены ничьей, отчет JSON сохранён.
- **FastAPI:** `/api/analysis?run=demo_endgame` и `/api/overview` проверены на тестовых исходных данных; статусы 200.
- **Frontend:** синтаксис JS проверен локально. Автоматический браузерный рендер v0.4 в этой среде не подтверждён (Chromium не был установлен); адаптивность наследует v0.3.

Веса реальной пользовательской модели с 27 итерациями не загружены: предоставлен только CSV. Поэтому end-to-end обновление этих **конкретных весов** проверить невозможно до запуска мигратора на пользовательском ПК.
