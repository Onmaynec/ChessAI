# Chess AI v0.5.0 — проверка релиза

- Исходники взяты из ZIP v0.4.0 с интегрированным v0.4.1 Dashboard Hotfix.
- Linux x86_64, Python + PyTorch CPU; CMake Release; C++ CTest пройден.
- 35 Python-теста (включая 7 новых): правомерность открытий, парность Evaluation, League PPO on-policy integrity, безопасное обновление из переименованной папки v0.4.1, порог сохранения best и API.
- На сохранении пользователя из ZIP `run_20261123_072154_6a110b.zip` checkpoint успешно загружен, создан `best.pt`, моделирование после `--resume` перешло с 170 на 171 (в пробном коротком запуске две партии не завершились, обновлений по исходу не было). Состояние AdamW осталось.
- Evaluation 2.0: 20 партий по 10 парным позициям, 20 разных последовательностей; 17 ничьих, 3 поражения, 0 побед, score 42,5%. seed=27, opening_plies=8, max_plies=400. Это тест разнообразия, **не доказательство прироста силы**.
- Старое Evaluation v0.4 имело лишь 2 различных сценария на 40 партий; исправлен протокол, не исходные данные.
- Проверки HTTP API и JavaScript синтаксиса пройдены; полный запуск Chromium на локальном адресе в текущем окружении заблокирован политикой среды, поэтому визуальный интерфейс браузера не подтверждён.
- Реальный Windows-установщик и GPU CUDA на машине пользователя ещё не проверялись.
