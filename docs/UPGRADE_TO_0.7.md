# Chess AI v0.7.0 — обновление и освобождение диска

## Порядок строго важен

1. В версии v0.6 нажмите **Stop after iteration**, дождитесь сообщения `RUN ENDED`. Если в PowerShell всё ещё активен `python -m neural.selfplay`, не запускайте перенос. Остановка посреди `torch.save` может испортить `latest.pt`.
2. Скопируйте **`runs/` из старой установки как отдельную резервную копию**. Особенно важны `checkpoints/latest.pt`, `checkpoints/best.pt`, `metrics.jsonl` и `run_metadata.json`. Перед запуском нового кода копия должна быть доступна независимо от новой папки.
3. Распакуйте v0.7.0 в отдельную папку; запустите `UPGRADE_FROM_CURRENT.bat` и введите точный путь к старой **корневой папке**. Мигратор сначала делает dry run, затем копирует `runs` по SHA-256. При несовпадении хеша/конфликте он не перезаписывает файлы.
4. Мигратор при наличии старой `.venv-cuda/Scripts/python.exe` создаёт `config/python_path.txt`. **Не удаляйте старую папку**, пока указанный в файле интерпретатор используется. Это намеренно: CUDA wheel PyTorch может занимать несколько ГБ.
5. Проверьте восстановление: `scripts/VERIFY_PROGRESS_WINDOWS.bat`. Номер `checkpoint_iteration` должен соответствовать последнему завершённому обновлению. Без успешной проверки **не продолжайте** обучение.
6. Остановив обучение, запустите `scripts/COMPACT_RUNS_WINDOWS.bat` и введите ID, например `run_20261123_072154_6a110b`. `YES` подтверждает сжатие; никаких весов и метрик скрипт не удаляет.
7. Запустите `START_CHESS_AI.bat`: в Training Studio должен быть `BUILD 0.7.0`. Убедитесь, что показываются исходные checkpoint, история и завершённые итерации.
8. Продолжите тот же эксперимент на 1–2 итерации, выбрав число одновременных партий и CPU workers. Начальная безопасная настройка: `parallel=8`, `bridge_workers=2`, PPO batch=64. Если `games_per_iteration=16`, можно отдельно проверить `parallel=16`.
9. Проверьте актуальность CUDA: `run_state.json > device_diagnostics` должен показывать `selected=cuda` при доступном CUDA-PyTorch. В панели откройте Диагностика → Performance для реальных времён и размера inference batch.

## Файлы, которые теперь экономят место

`experience.jsonl` / `games.jsonl` / `arena_games.jsonl` → `archives/<имя>/0000001_<sha256>.jsonl.gz`, затем следующие сегменты. При распаковке исходные байты проверяются по SHA-256 **до** удаления несжатого журнала. Новый код читает историю из архива и текущего журнала вместе. Формат `latest.pt` остаётся неизменным.

**Не удаляйте вручную** ни `archives`, ни `checkpoints`: архивы содержат полные игровые данные и опыт, а checkpoint — веса + состояние оптимизатора. Чтобы восстановить конкретный сегмент вручную, используйте стандартный gzip, **не создавая дубликат внутри active журнала**. На каждое сжатие требуется дополнительное место примерно под размер сжатого сегмента; сжатие не требует ещё одной полной несжатой копии.

## Если произошёл сбой во время архивации

Если `archives/.../<sha256>.jsonl.gz` опубликован, но старый `.jsonl` ещё существует, при следующей безопасной архивации система сверит хеш полного разжатого архива и оригинала, и удалит только **байтовый дубликат**. Если исходный журнал изменён, копия не удаляется автоматически. Для незавершённых итераций при возобновлении создаётся `recovery/*.full-original.gz` и сохраняются отдельно незафиксированные строки.

## Ограничения и честные ожидания

- Сжатие уменьшает **диск**, а не количество параметров нейросети. Оно не является алгоритмом повышения Elo.
- Автоматические архивы создаются только **после checkpoint**, раз в 5 завершённых итераций по умолчанию. Между ними несжатый журнал может временно расти.
- Перенос сохраняет старую папку неизменной, поэтому до завершения уборки диска обе папки требуют место. Только после проверки нового обучения и независимого бэкапа можно самостоятельно решить, удалять ли старую копию.
- Фактическая скорость CPU workers и CUDA зависит от нагрузки. Для корректного сравнения используйте одинаковые checkpoint, параметры, seed и контрольные серии.
- Этот релиз протестирован в Linux с CPU PyTorch. Windows BAT/CUDA-мультипроцессинг должны пройти первый тест на вашем Windows ПК.
