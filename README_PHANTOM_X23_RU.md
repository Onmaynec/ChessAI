# Chess AI v0.8.0 — Фантом-X23 · дебютное обучение за белых

Это **отдельный установочный патч поверх v0.7.9.1**. Он сохраняет исправления Vision Bot и все предыдущие checkpoint. Исходный эксперимент: `run_20261123_072154_6a110b`.

## Как использовать без нового обучения

1. Закрой Vision Bot и Training Studio. Распакуй архив.
2. Запусти `INSTALL_PHANTOM_X23.bat` **из папки распакованного патча** и укажи папку установленного `ChessAI-v0.7.0`.
3. Открой `START_CHESS_VISION_BOT.bat` **из установленной папки**.
4. Играй только против компьютерного бота, белыми; включи галочку **«Фантом-X23 за белых»**. Выбери любую существующую модель: `latest.pt`, `skillboost_v2.pt` или `aggressive.pt` (если создана).
5. В новой партии со стартовой позиции программа попробует `1.Nf3` и известные продолжения. Если чёрные отклоняются от проверенной последовательности, бот **сразу переходит на обычный тактический поиск**. Дебютный ход не может обойти проверку безопасности. При подключении к партии *без истории* дебютная книга не применяется.

Это **дебютная книга** для любого агента, не изменение весов. В дебюте есть ловушки, но против сильной защиты они не являются форсированным выигрышем.

## Как действительно дообучить веса

1. Дождись сохранения текущей итерации и штатно останови основное PPO (не делай два интенсивных обучения на одной GPU одновременно).
2. Открой **Training Studio → Диагностика модели → Agent Lab → «Обучить Фантом-X23»**. Или запусти `TRAIN_PHANTOM.bat` из установленной папки.
3. Отдельный тренер выберет исходный checkpoint в порядке: `aggressive.pt` → `skillboost_v2.pt` → `skillboost.pt` → `latest.pt`. Можно указать другой источник через CLI `--source skillboost_v2.pt`.
4. В случае улучшения внутренней контрольной ошибки будет создан новый файл `runs/run_20261123_072154_6a110b/checkpoints/phantom.pt`. Выбери его в Vision Bot. **Выполнять дебютную книгу можно и без этого файла.**

Тренер обучается на **уникальных позициях четырёх иллюстративных PGN-линий** через проверку каждого хода C++-движком. Это небольшая, коррелированная выборка. Добавлена регуляризация к исходной модели и, если доступны, ранее созданные **локальные** учебные позиции SkillBoost для уменьшения забывания. Контрольная ошибка на части этих же линий **не доказывает реального усиления**. Нужны отдельные матчи против эталона и проверки на отклонениях соперника.

`phantom.pt` создаётся **только как независимый кандидат**. Не перезаписываются `latest.pt`, `lasttest.pt`, SkillBoost I/II, Aggressive, Defender, состояние PPO-оптимизатора и накопленная история.

## Дебютные варианты

В `docs/Phantom_X23_White.pgn` есть четыре линии: ловушка Qxh7#, ловушка Qh8#, вариант защиты с ...c4 и техническая схема против чёрного фианкетто. Все последовательности проходят проверку шахматных правил.

## Что делать, если дебют не включается

- Выбраны чёрные или партия начата не с исходной расстановки: Фантом не применяется.
- Соперник отклонился от точной последовательности: модель рассчитывает ход самостоятельно.
- Выбранный книжный ход уступает альтернативам по тактической оценке: бот может отклонить его.
- Если уже есть активный журнал восстановления партии, его сохранённый выбор дебютного режима имеет приоритет при восстановлении.

## Резервные копии

Установщик сохраняет заменяемые файлы в `patch_backups/phantom_x23_...` и проверяет SHA-256. `runs/` в списке файлов обновления отсутствует.
